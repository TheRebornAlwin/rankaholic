Privacy Policy

RankaHolic · last updated 8 October 2026

Who this covers

RankaHolic operates private, internal tools that publish videos to and read statistics from its own social media accounts. These tools are not distributed, not offered to other people, and have no users other than the channel owner.

What data is accessed

With the channel owner's own Google account authorisation, the tools access, via the YouTube Data API and YouTube Analytics API:

  • video metadata for the channel's own videos (titles, descriptions, publish times)
  • aggregate statistics for those videos (views, watch time, average view duration, subscribers gained)
  • public comments left on those videos, in order to reply to them

No data is accessed from any account other than the channel owner's own.

How it is stored

Data is stored in local database files on the channel owner's own computer. It is not uploaded to any third-party service, not shared, not sold, and not used for advertising or profiling. Access tokens are stored locally and are used only to call Google's APIs.

Commenters

Comments are already public on YouTube. The tools store a comment's text, its public author name, its like count and its timestamp, solely so the channel can keep track of which comments have been answered. This information is not used for any other purpose and is not shared.

Retention and deletion

Stored data is kept only as long as it is useful for running the channel and can be deleted at any time by deleting the local database files. To request removal of a comment or its stored copy, email the address below.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Authorisation can be revoked at any time at myaccount.google.com/permissions.
